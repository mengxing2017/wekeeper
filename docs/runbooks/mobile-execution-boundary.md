# 手机发送的执行边界

平台负责目标群名、消息正文、学校授权、业务发送间隔、资源调度、人工确认及结果核对。手机负责企业微信页面识别、群搜索、文字输入和本地执行适配。平台不安装或下发手机 UI 规则，也不要求测试手机或规则包才能创建、预览、确认任务。

新任务冻结 `execution: {contract: "device_owned/1", capability: "wecom.group_text"}`，不包含 `flow`、`flow_digest`、`release_id` 或运行配置标识。传输继续使用 v9 和 `shared_mobile_send/2`，历史快照及恢复凭据保持原样。

手机领取后根据群名搜索并选择第一个结果，自行完成发送准备。准备回报携带 attempt、租约 fence、计划及正文摘要、页面摘要和输入匹配事实，不需要 flow 摘要。随后申请单次发送许可；准备成功不代表已发送。无法执行时由手机回报该次尝试的实际错误。手机离线、锁屏和本地适配失败只影响执行，不阻止平台受理业务任务。

已有手机客户端须支持 `device_owned/1`，将原本依赖服务端 flow 的执行入口改为手机本地实现。此仓库不包含该独立 Android 客户端；本次平台修改不声称已完成手机端适配或真实发送验证。旧客户端不得把缺少 flow 当作成功发送。

不确定结果仍保持 unknown 核对，禁止自动重发；身份授权、学校边界、单次许可、物理租约和配额继续生效。历史已领取任务保留原快照及恢复链；仅终止尚未领取的自动页面检查，不释放正在执行的物理资源。
