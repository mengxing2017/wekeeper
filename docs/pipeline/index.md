# 业务与发送流程

当前手机业务使用[手机共享发送使用手册](../guide/operator/mobile-execution-tasks.md)，办理步骤见[手机使用管理](../guide/platform-admin/shared-mobile-resources.md)和[手机任务](../guide/operator/mobile-execution-tasks.md)。

## 身份、工作空间与内容

1. 系统管理员维护两类独立分发工作空间及对应成员授权。
2. 企业微信配置已核实官方成员、客户群与模板，使用来源素材或直接文本准备任务；论坛内容在 linjian 管理。
3. 移动端在独立工作空间管理目标群和任务，设备及使用范围另行授权。
4. 后端验证身份、工作空间、依赖版本和冻结快照，记录审计。

媒体默认存 PostgreSQL BYTEA，随数据库备份；旧媒体与整数 ID 迁移采用明确映射，不猜测历史身份。切换与导入步骤见 [业务运行手册](../runbooks/business.md)。

## 官方企业微信群发

草稿 → 预览与人工确认 → API 内 worker 单次领取 → 官方创建任务 → 成员在企业微信执行 → 按群读取官方状态与人工核对。

直接文本确认要求对应分发工作空间 admin；官方 msgid 不是送达证明。创建、提醒、停止出现不确定结果时不自动重放，停止不能撤回已发消息。配置和真机要求以 [企业微信手册](../runbooks/wecom.md) 为准。

## 手机执行

人工确认冻结逐群任务 → 独立设备凭据领取 → 观察身份并准备 → 获取一次性 permit → 原生本地消费后单次动作 → 固定结果回报 → unknown 人工核对。

Android 为独立 keeper-otter 项目，WeKeeper 不新增电脑网关或任意远控服务。后端实现不代表微信/企业微信原生适配已验收，执行依赖实际 UI 规则和手机现场条件；测试结果不能代替实际发送回执，研发验收记录不参与运行时放行。

跨通道共享规范账号/群、额度、去重和 unknown 记录，不能切换设备或通道规避历史。手机发送确认和结果处理见 [手机共享发送使用手册](../guide/operator/mobile-execution-tasks.md)。

## 验收边界

类型检查、HTTP 契约或模拟平台测试不代表真实平台权限、真机行为或生产切换完成。先使用隔离数据库验证流程，再按运行手册逐项进行授权范围内验收。unknown 不自动解释为失败，也不以重试写入确认结果。
