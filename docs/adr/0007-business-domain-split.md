# ADR 0007：业务域与平台中立内容来源

状态：已采用。

当前只有 backend/frontend 两个部署应用，共享一个数据库和分发登录体系。业务范围为消息接收、企业微信分发、手机分发与系统管理。

手动官方群发只接受直接填写的正文。外部消息通过独立鉴权的来源路由接入，按业务接收配置冻结正文、目标与授权候选；配置变化只影响新消息。浏览器不能自行指定外部来源身份或通过 `confirmed=true` 获得执行授权。

官方任务持有独立不可变消息快照。服务端预览绑定正文、目标、凭据范围和来源政策；人工确认核验摘要、修订和期限。草稿请求按来源和操作者使用显式幂等键，重试不创建第二个投递意图。

项目尚未上线且没有历史业务数据，migration 已按当前领域模型重建为空库初始化基线，不创建退场业务表；后续结构变更新增递增的前向 migration。当前分发快照、执行授权、结果和审计继续保留。即时消息不接受内容撤回或版本替换控制，发送结果与 unknown 保留实际执行证据。

来源政策和官方资源预算不替代手机单次调用授权。手机分发遵守 [ADR 0008](0008-mobile-candidate-dispatch.md) 的候选调度与 unknown 核对语义。
