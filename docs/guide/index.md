# 使用手册

先选择你的工作角色。只想完成日常操作时，从下面的清单开始，不需要先读开发文档。

| 你的工作 | 从这里开始 | 完成后能做什么 |
| --- | --- | --- |
| 处理内容、执行学校运营 | [业务人员每日清单](operator/index.md) | 审核内容、准备发送并核对结果 |
| 负责一所学校的配置 | [学校管理员准备清单](school-admin/index.md) | 确认学校、成员、客户群和发送范围 |
| 负责整个系统 | [平台管理员上线清单](platform-admin/index.md) | 建学校、分配账号授权、同步目录和准备设备 |
| 第一次登录 | [快速开始](quick-start.md) | 找到当前学校和自己的工作入口 |
| 页面报错或任务不动 | [常见问题](troubleshooting.md) | 确定下一步及应联系谁 |

平台管理员、学校管理员和运营是不同身份。能看见一个菜单，不代表能替另一所学校确认发送；操作仍以服务端授权结果为准。

## 先分清这三组名称

- **客户群总览**是平台同步企业微信客户群目录；**客户群**是学校关联并使用的群。
- **登录账号管理**管理登录后台的人；**手机设备 / 发送账号**管理实际执行任务的手机和业务账号。
- **群发任务**走企业微信官方任务；**手机发送任务**由独立手机执行端完成。两者的确认步骤和结果证据不同。

更多解释见[术语与状态](glossary.md)。开发、部署和升级请进入[开发者手册](../development/index.md)或[部署与运维](../operations/index.md)。

## 管理端功能分区

- **业务功能**：内容审核、客户群、模板与发送任务、手机设备、发送账号；客户群总览为全平台受限业务视图。
- **平台功能**：学校管理、学校设置、企业微信集成、平台默认展示配置。学校设置仍限定当前学校。
- **系统功能**：登录账号管理、平台管理员、学校成员与权限、操作审计。

分区表示功能用途，访问权限由账号角色和学校授权决定。全平台页面标注“范围：全平台”，学校页面需核对“当前学校”。发送账号与管理端登录账号分别维护。
