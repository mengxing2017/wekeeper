# 使用手册

WeKeeper 接收下游消息，并提供企业微信分发和移动端分发；两类分发使用独立工作空间。

| 工作 | 操作说明 |
| --- | --- |
| 第一次登录 | [快速开始](quick-start.md) |
| 维护工作空间及权限 | [独立分发工作空间](workspaces.md) |
| 接收下游消息 | [调用方凭据与路由授权](operator/source-access.md) |
| 企业微信发送 | [客户群与模板](operator/groups-and-templates.md)、[群发任务](operator/broadcast-tasks.md) |
| 手机发送 | [手机任务](operator/mobile-execution-tasks.md)、[手机目标群](operator/mobile-targets.md) |
| 系统维护 | [系统上线清单](platform-admin/index.md) |

论坛及学校、论坛成员与账号管理由独立 linjian 提供。两类分发的账号授权、目标群和发送确认由 wekeeper 自行维护。完整范围见[业务域](business-domains.md)。
