# 第一次登录

向部署负责人领取站点地址及分发登录账号，在登录工作空间页面登录。密码和会话属于 wekeeper，不使用论坛 linjian 的会话。

1. 核对账号菜单中的姓名和身份。
2. 进入企业微信分发或手机任务、手机目标群，核对对应分发工作空间。
3. 没有业务菜单时，请系统管理员在对应通道授予独立工作空间权限。
4. 运营可准备任务，分发管理员确认发送前核对正文、目标与授权；系统管理员还可维护目录、设备与分发权限。

学校管理、学校设置、学校成员与权限及登录账号管理已迁出。当前权限规则和开通步骤见[独立分发工作空间](workspaces.md)。

忘记密码请联系部署负责人；系统管理员可在“系统管理员”页面重设管理员密码，重设后该账号须重新登录。
