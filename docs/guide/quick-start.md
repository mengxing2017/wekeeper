# 第一次登录与开始工作

适合第一次使用后台的业务人员、学校管理员和平台管理员。这一页帮助你进入正确学校并找到自己的工作。

## 开始前

向管理员领取站点地址、登录账号和初始密码。不要使用示例密码，也不要把账号密码填到截图或问题反馈中。没有账号时，由平台管理员按[账号、学校与授权](platform-admin/accounts-and-schools.md)准备。

![登录工作空间：填写管理员分配的账号和密码，底部可打开登录与使用帮助](/images/guide/login.png)

图为当前 Web 构建的真实页面，未填写账号密码。

## 按顺序操作

1. 打开站点的 `/admin`。在“登录工作空间”填写“账号”“密码”，点击“登录”。
2. 看右上角账号菜单，核对当前身份。平台管理员不等于拥有所有学校的业务授权。
3. 在业务页面的“当前学校”选择本次要操作的学校。每次处理内容、配置群或确认任务前都再核对一次。
4. 业务人员从“内容审核”开始；学校管理员先看“学校设置”“学校成员”；平台管理员先看“学校管理”“账号管理”。
5. 点击页面标题下的“使用说明”查看当前页面步骤；顶栏“帮助中心”可以随时返回本手册。

![工作台示例：左侧业务导航、右侧当前学校、顶栏帮助中心和标题下的使用说明](/images/guide/workspace.png)

图中“示例管理员”“示例学校（教学数据）”均为隔离示例数据，不对应真实人员或学校。

完成后，应看到自己的账号、当前学校及可用菜单。文档通过普通链接打开，浏览器后退可回到原工作台地址；不要把文档中的示例地址当成真实学校数据。

## 遇到问题

- 登录失败：核对账号、密码与是否停用，联系平台管理员；不要反复创建新账号。
- 登录后没有学校或菜单：通常缺少学校授权，按[角色与学校](roles-and-schools.md)核对。
- 一直确认登录状态或服务不可用：先阅读[故障处理](troubleshooting.md)，管理员检查站点与 API。
