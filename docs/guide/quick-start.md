# 第一次登录

向部署负责人领取站点地址及分发登录账号，在登录管理后台页面登录。使用 wekeeper 独立的登录账号与会话。

1. 核对账号菜单中的姓名和身份。
2. 进入企业微信分发或手机任务、手机目标群，核对对应全局分发资源。
3. 没有业务菜单时，请系统管理员在对应通道授予全局系统管理员权限。
4. 运营可准备任务，分发管理员确认发送前核对正文、目标与授权；系统管理员还可维护目录、设备与分发权限。

学校管理、学校设置、学校成员与权限及登录账号管理已迁出。当前权限规则和开通步骤见[全局分发权限](workspaces.md)。

忘记密码请联系部署负责人；系统管理员可在“系统管理员”页面重设管理员密码，重设后该账号须重新登录。

登录后默认进入[统计概览](operator/message-statistics.md)，位于导航最顶部。直接打开消息或任务链接时，会保留对应页面。
