# 三个业务域与公共支撑

| 业务域 | 管理什么 | 从哪里开始 |
| --- | --- | --- |
| 论坛管理 | 内容、评论、举报反馈、展示与屏蔽词 | [审核治理](operator/moderation.md) |
| 企业微信分发管理 | 官方客户群、模板、群发任务、发送账号、群总览及集成 | [官方群发](operator/broadcast-tasks.md)、[官方身份](operator/official-senders.md) |
| 移动端分发管理 | 共享手机、独立目标群、能力开通、共享手机任务 | [手机目标群](operator/mobile-targets.md)、[共享资源](platform-admin/shared-mobile-resources.md) |
| 平台与系统管理 | 学校、成员、平台登录身份及公共审计 | [学校与权限](school-admin/settings-and-members.md) |

业务归属与操作范围是两个维度。平台默认展示配置属于论坛，但只允许平台维护；客户群总览属于官方渠道，但仍是平台范围。

论坛审核不会自动创建任务。选择渠道只建立草稿，随后需要独立预览和人工确认。
官方失败不会自动改手机，手机失败也不会改官方。原调用结果不确定时，应先核对原任务。

官方客户群是官方目录身份，手机目标群是学校独立的搜索目标；同名不能当作同一个真实群。
设备备注不是账号认证，不会与官方成员自动关联。

手机能力未开放时，任务页保持阻断。未上线且无数据的历史手机任务入口已移除，不保留旧任务兼容流程。

本次拆分保留现有数据库、登录及部署。论坛未来迁出需要另行实施，当前不宣称已具备外部多租户接入。
