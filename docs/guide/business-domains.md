# 业务域与操作范围

| 业务域 | 内容 | 权限范围 |
| --- | --- | --- |
| 消息接收 | 调用方凭据、下游消息推送与消息分发路由 | 全局业务范围，当前由系统管理员维护 |
| 企业微信分发 | 官方成员使用、客户群、模板、群发任务、资源策略 | 独立企业微信工作空间 |
| 移动端分发 | 手机任务、手机目标群、设备绑定、共享手机使用管理 | 独立移动工作空间；设备为系统资源 |
| 系统管理 | 系统管理员维护、操作审计 | 系统管理员权限 |

两类工作空间独立创建和授权，见[工作空间管理](workspaces.md)。官方客户群与手机目标群是不同业务身份，不能因同名相互替代。

论坛管理、学校成员与权限、学校设置、学校管理、登录账号管理以及整个小程序由 linjian 承接。wekeeper 保留分发登录、目标、任务、授权和结果，不读取论坛或学校主数据。
