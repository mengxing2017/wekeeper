# 学校管理员准备清单

适合负责一所学校业务的管理员。开始前由平台管理员创建账号并授予本校 admin；平台身份与学校身份要分别核对。

1. 登录并选择本校，检查“学校设置”中的名称、状态和审核方式。
2. 在“学校成员与权限”核对运营账号和角色；缺少授权请平台管理员处理。
3. 准备学校客户群与消息模板。候选为空时先排查企业成员绑定和平台目录同步。
4. 使用官方通道时，核对本校群主和企业微信权限；使用手机通道时，核对设备、发送账号和已发布流程。
5. 先在隔离测试学校与测试群完成一次完整预览、确认、结果查看与异常交接。
6. 开放日常操作后定期查看本校审计和结果不确定任务。

完成后，运营应能选择本校并完成其授权内的工作；管理员应能解释谁负责确认发送、谁负责排障。
