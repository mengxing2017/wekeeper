# 学校发送前的准备

适合本校管理员。先完成[学校准备清单](index.md)，再根据实际通道准备；不要默认同时启用所有能力。

## 官方群发

1. 由平台管理员同步企业通讯录和客户群目录。
2. 核对本校管理账号的企业成员绑定，从候选关联本校客户群；学校管理员需要满足群主等校验。
3. 如使用模板，准备并发布所需版本。
4. 在“群发任务”创建测试草稿，预览正文和范围，再由本校管理员确认；执行成员到企业微信完成发送。

服务端官方能力关闭时，请部署负责人核对开关与平台权限，不需要业务人员修改环境变量。

## 手机发送

1. 由平台管理员登记配对手机、真实发送账号和群可见资料，发布已真实验证的流程。
2. 在“手机发送任务 → 执行设备与账号”选择手机或设备组，再选择“已发布通用流程”，点击“为所选范围分配”。
3. 核对历史任务及其他通道未决发送，勾选“已核对本校历史与其他通道的未决发送，再开启手机执行”，点击“启用学校 v5 执行”。
4. 在“配置消息”确认可以选到分配，交业务人员按[手机任务手册](../operator/mobile-tasks.md)操作。

离线设备可分配和排队，不代表无需升级执行端或无需手机授权。设备组在确认时展开为明确成员，后来增减组成员不会改变已确认任务。

## 完成后

本校能够看到正确的群、设备账号分配和测试任务结果。无法选择流程时联系平台维护人员；不提供真实验证证据时，不能用默认示例流程上线。
