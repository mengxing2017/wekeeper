# 学校发送前的准备

适合本校管理员。先完成[学校准备清单](index.md)，再根据实际通道准备；不要默认同时启用所有能力。

## 官方群发

1. 由平台管理员同步企业通讯录和客户群目录。
2. 核对本校管理账号的企业成员绑定，从候选关联本校客户群；学校管理员需要满足群主等校验。
3. 如使用模板，准备并发布所需版本。
4. 在“群发任务”创建测试草稿，预览正文和范围，再由本校管理员确认；执行成员到企业微信完成发送。

服务端官方能力关闭时，请部署负责人核对开关与平台权限，不需要业务人员修改环境变量。

## 手机共享资源

1. 在本校目标群页维护独立目标群，由平台绑定共享手机；手机不归属于学校，也不要求旧发送账号或学校专属流程。
2. 平台完成手机业务能力开通，由现场人员原生确认。学校需要现场检查时，针对当前群绑定发出检查邀请，再由平台和手机人员共同完成不发送消息的检查。
3. 当前共享任务执行链路尚未完成，不能通过检查、旧发布或旧成功结果启用发送。待单次调用、回报和真机验收完成后，再按预览与人工确认流程使用。

官方客户群、官方群发和手机目标群相互独立，保留现有官方业务。手机历史任务及 unknown 仍需按原记录核对，不自动重发。
