# 学校发送前的准备

适合本校管理员。先完成[学校准备清单](index.md)，再根据实际通道准备；不要默认同时启用所有能力。

## 官方群发

1. 由平台管理员同步企业通讯录和客户群目录。
2. 核对本校管理账号的企业成员绑定，从候选关联本校客户群；学校管理员需要满足群主等校验。
3. 如使用模板，准备并发布所需版本。
4. 在“群发任务”创建测试草稿，预览正文和范围，再由本校管理员确认；执行成员到企业微信完成发送。

服务端官方能力关闭时，请部署负责人核对开关与平台权限，不需要业务人员修改环境变量。

## 手机群消息

在本校目标群的使用管理中，选择手机和群（可同页新增群），核对额度、期限和业务方案后确认。原批准范围内直接使用，其余范围等待平台审批。产品交付和现场条件分别显示，不需要学校维护技术规则或安装包。

现场人员只需首次启用手机托管，设置系统权限、保持后台连接和解锁。随后按[两步发送](../operator/mobile-execution-tasks.md)填写并预览，核对后确认发送。

官方客户群和手机目标群相互独立。结果不确定须人工核对，不自动重发。
