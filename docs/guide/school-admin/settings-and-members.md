# 学校设置与成员

适合学校管理员；平台管理员负责全平台授权维护。开始前确认“当前学校”，停用学校或无授权学校不能作为普通业务范围。

## 学校设置

入口：“平台功能 → 学校设置”。核对学校信息、审核方式与主题颜色，再提交目标设置。更改审核方式前与运营确认影响；保存后刷新，并从校园社区检查可见结果。

## 学校成员

入口：“系统功能 → 学校成员与权限”。搜索并核对成员、角色和有效状态。学校管理员可以阅读本校成员，学校授权由平台管理员维护。

需要增加运营或管理员时，向平台管理员提供学校名、账号名和工作职责。对方处理后重新登录或刷新核对；不要把企业成员绑定当作学校授权，绑定企业身份不会自动授予本校权限。

## 完成与排障

完成后应看到正确学校信息及获授权人员。菜单缺失、学校停用或无权限时，联系平台管理员检查状态与授权；不要向其他人转交管理员密码。

操作审计可追踪关键变更，只能查看授权范围。下一步：[发送前准备](delivery-setup.md)。
