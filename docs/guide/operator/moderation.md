# 内容、评论、举报与展示管理

适合当前学校的运营和学校管理员。开始前确认学校，并了解本校的审核标准；标准由学校负责人决定，本手册不替代内容判断。

![内容审核页面与当前学校、帮助入口的位置，列表为空的隔离示例](/images/guide/workspace.png)

截图使用示例数据；实际记录取决于当前学校与筛选。

## 审核内容

入口：“内容运营 → 内容审核”。

1. 用筛选和搜索找到要处理的记录，打开详情阅读正文与图片。
2. 根据实际内容进行审核或展示状态调整。提交前核对是本条记录及当前学校。
3. 刷新或回到列表检查状态，再从“校园社区”确认用户能看到的结果。
4. 正文更新可能重新进入待审核，不能把之前通过理解为之后永远通过。

## 评论、举报与反馈

“评论审核”用于评论与回复；“举报与反馈”用于处置用户提交的问题。先看关联内容和处置记录，再提交结论。处理完成后确认记录状态，不只关闭抽屉。

## 展示与屏蔽词 {#display-resources}

入口：“展示与屏蔽词”。核对本校的展示资源、服务入口和内容规则，再修改目标项目。完成后查看社区实际展示；找不到学校配置时请学校管理员协助。平台默认配置由平台管理员在“平台展示配置”维护，不能混为一份学校设置。

## 遇到问题

记录不存在或已变化：刷新后重新核对，不用旧页面直接重放操作。没有编辑权限：联系学校管理员。图片无法显示：记录发生时间和资源名称，请部署人员排查，勿改用第三方地址绕过学校访问限制。
