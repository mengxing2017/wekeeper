# 官方企业微信群发任务

适合学校运营及本校管理员。入口：“企业微信 → 群发任务”。这是企业微信官方任务通道，与手机发送分别操作。

## 开始前

由管理员准备本校客户群、有效群主/企业成员绑定及服务端官方能力。页面显示能力关闭或读取失败时，先交管理员处理。直接文本任务必须由本校管理员确认，平台管理身份不能替代学校授权。

## 按顺序操作

1. 新建群发任务草稿，选择直接文本或已有内容和已发布模板，填写正文及范围。
2. 保存草稿后打开详情，检查正文预览、群主与目标群。草稿尚未发送。
3. 由有权限的人逐项核对，点击“确认创建企业微信群发任务”，完成确认对话框。
4. 后台创建官方任务后，查看任务 ID 和执行成员。请对应成员到企业微信的群发助手完成确认发送。
5. 在原任务详情同步和查看各群结果；只在需要时按页面操作提醒尚未执行成员。

## 完成后应该看到什么

“已创建，等待成员执行”表示官方接受创建，不是所有群已送达。最终查看逐群官方状态及核对证据。任务 ID 也不是送达凭证。

## 遇到问题

- 没有提交按钮或提示没有本校管理员权限：请学校管理员打开同一草稿处理。
- 官方权限、可信 IP 或额度错误：由平台管理员检查[企业微信接入](../../runbooks/wecom.md)。
- 创建结果不确定：留在原任务核对，不再次新建相同发送。停止或提醒也可能出现不确定结果。
- 停止后：检查逐群状态，不能将停止理解为撤回已经发送的内容。
