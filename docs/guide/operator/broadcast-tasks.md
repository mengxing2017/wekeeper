# 官方企业微信群发任务

适合工作空间运营及当前工作空间管理员。入口：“企业微信分发管理 → 群发任务”。这是企业微信官方任务通道，与手机发送分别操作。

## 开始前

由管理员准备当前工作空间客户群、有效群主/企业成员绑定及服务端官方能力。页面显示能力关闭或读取失败时，先交管理员处理。直接文本任务必须由当前工作空间管理员确认，系统管理身份不能替代工作空间授权。

## 按顺序操作

1. 选择客户群，填写正文或选择内容和模板，点击“预览”。系统自动保留草稿并展示最终正文、全部目标及执行成员，无需先保存再打开详情。
2. 核对完整范围后，由有权用户确认创建。直接文本仅当前工作空间管理员确认；已过期或条件变化时重新预览。

服务端凭据未配置、官方接口暂不可用或目标未准备时仍可保存正文草稿，页面说明等待事项；不会生成可外发批次。渠道恢复不自动提交草稿。

后台受理和成员在企业微信确认是后续状态。创建完成后，请执行成员到企业微信群发助手确认，随后在原任务同步逐群结果。系统确认不代表消息已经送达。

来源路由自动任务由已授权链路自动创建并持续同步结果，无需在本平台逐条预览、确认或审批。成员在企业微信客户端确认属于外部通道操作；平台显示“已创建，等待成员执行”，不会因此生成平台人工确认工单。上述手动任务的两步操作仍适用于用户主动创建的任务。

## 完成后应该看到什么

“已创建，等待成员执行”表示官方接受创建，不是所有群已送达。最终查看逐群官方状态及核对证据。任务 ID 也不是送达凭证。

任务详情的“执行观察记录”区分官方任务创建、微信侧成员执行和逐群结果。结果读取失败会自动退避查询，并保留已取得的成功事实；创建结果不确定时不会自动重复创建。官方报告本群已发送不表示群内每个成员已经阅读。

## 遇到问题

- 没有提交按钮或提示没有当前工作空间管理员权限：请分发管理员打开同一草稿处理。
- 渠道未就绪：填写业务用途，确认提交开通申请；在原页查看负责人及答复。接入由部署负责人处理。
- 创建结果不确定：留在原任务核对，不再次新建相同发送。停止或提醒也可能出现不确定结果。
- 停止后：检查逐群状态，不能将停止理解为撤回已经发送的内容。

下一步：[结果与异常处理](results-and-recovery.md)。

## 来源与撤回

论坛内容经受控素材端口读取，任务保留自己的正文快照。直接文本不要求帖子或论坛用户资料。
来源变更或撤回会阻断尚未调用部分；已创建官方任务及 unknown 保留证据，不能承诺自动撤回。
来源暂不可用时不会默认放行。草稿保存重试保持同一幂等键，正文或目标改变后生成新的保存意图。
