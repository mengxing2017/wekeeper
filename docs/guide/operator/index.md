# 业务人员每日工作清单

适合学校运营与承担日常业务的学校管理员。前提是账号已获得当前学校授权。

## 每天开始时

1. 登录后核对“当前学校”和右上角身份。
2. 在“内容审核”“评论审核”“举报与反馈”查看待处理事项，按学校规则处理。
3. 需要发消息时，先确认使用“群发任务”还是“手机发送任务”。不知道选哪种时向学校管理员确认，不要把同一条消息在两个通道各发一次。
4. 官方任务确认前核对正文与目标客户群；手机任务确认前另外核对手机、发送账号、群顺序和间隔。
5. 创建后在原任务查看进度，不以新建任务替代刷新或核对。
6. 下班前查看未完成与结果不确定的任务，将证据和待处理事项交接给负责人。

完成每日工作后，应能找到已处理记录和任务结果。没有相应按钮或操作被拒绝时，联系学校管理员核对角色，不要借用管理员账号。
