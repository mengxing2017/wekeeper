# 官方发送成员与学校范围

入口：企业微信分发管理 → 发送账号。学校只查看本校范围，平台负责人处理跨校授权和申请。

## 配置学校使用范围

1. 选择学校、已核实企业成员、明确登录账号、学校职责和本人担任群主的客户群，点击“核对使用范围”。已有身份和职责会复用，不按同名自动绑定账号。
2. 核对成员、账号、职责和群名后确认。有权限直接办理；身份或职责变化需要平台审批时，提交申请，在原页查看负责人和答复。申请提交不提前授予权限。

目录没有准备、群已属其他学校、群主变化或账号绑定冲突时，由平台负责人核对后重选。不默认提升学校管理员职责；新建登录账号仍由账号管理负责。

“基础条件满足”不等于本次发送许可。渠道、群目录时效、人工确认和资源限制在发送前重新校验。平台身份不能替代本校确认权限。

## 调整成员限制

平台在资源治理中按成员姓名选择，编辑窗口、允许次数与暂停状态，核对影响后确认。用量跨学校、跨来源累计；页面显示当前用量和额度恢复时间，不承诺官方安全发送次数。

内部计量由系统维护，调整政策或绑定账号不会重置原账本。暂停阻止后续调用，不改变历史结果。来源积压控制按业务来源展示。手机状态在手机使用管理查看。

## 申请和问题

在申请列表查看学校、事项、负责人、状态、答复和处理历史。平台负责人查看实际范围，可分派处理人、请求补充或批准/退回。批准开通申请本身不安装凭据；实际渠道状态由交付检查决定。
