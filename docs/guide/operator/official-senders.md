# 官方发送账号与资格

入口：“企业微信分发管理 → 发送账号”。系统管理员全局管理真实发送身份及发送资格，不选择业务资源或成员角色。

## 配置官方身份

1. 选择已核实企业成员、已有登录账号及该成员担任群主的客户群，点击“核对使用范围”。不按同名自动绑定账号。
2. 核对成员、账号、群名，以及预览列出的身份关联、发送资格启用和停用群恢复动作后确认。目录未准备、群主变化或账号绑定冲突时刷新核验。

系统管理员账号也可关联官方成员。绑定与使用范围确认共用最近 24 小时已核实、启用且可见的通讯录规则；更换关系先显式解绑，解绑不依赖目录可用性。

账号绑定、官方成员、群主、企业权限和真实发送资格分别校验。停用发送资格阻止后续调用，不修改历史结果。

## 调整成员限制

按成员姓名选择，编辑调用窗口、次数和暂停状态，核对影响后确认。用量全局、跨来源累计；修改政策或账号绑定不清空账本。这里的业务额度不承诺官方安全发送次数。

手机设备、目标群、使用期限和额度在手机使用管理维护。渠道运行状态显示真实官方接口检查结果；系统管理员可独立暂停或恢复新发送，连接恢复不会解除人工暂停。
