# 官方发送成员与工作空间范围

入口：企业微信分发管理 → 发送账号。工作空间只查看当前工作空间范围，系统负责人处理跨工作空间授权和申请。

## 配置工作空间使用范围

1. 选择工作空间、已核实企业成员、明确登录账号、工作空间职责和本人担任群主的客户群，点击“核对使用范围”。已有身份和职责会复用，不按同名自动绑定账号。
2. 核对成员、账号、职责和群名后确认。有权限直接办理；身份或职责变化需要系统管理员审批时，提交申请，在原页查看负责人和答复。申请提交不提前授予权限。

目录没有准备、群已属其他工作空间、群主变化或账号绑定冲突时，由系统负责人核对后重选。不默认提升分发管理员职责；本页选择已有分发账号，不创建普通登录账号。

“基础条件满足”不等于本次发送许可。渠道、群目录时效、人工确认和资源限制在发送前重新校验。系统管理员可直接管理工作空间；普通账号须获当前工作空间管理员授权才能确认。

## 调整成员限制

系统在资源治理中按成员姓名选择，编辑窗口、允许次数与暂停状态，核对影响后确认。用量跨工作空间、跨来源累计；页面显示当前用量和额度恢复时间，不承诺官方安全发送次数。

内部计量由系统维护，调整政策或绑定账号不会重置原账本。暂停阻止后续调用，不改变历史结果。来源积压控制按业务来源展示。手机状态在手机使用管理查看。

## 申请和问题

在申请列表查看工作空间、事项、负责人、状态、答复和处理历史。系统负责人查看实际范围，可分派处理人、请求补充或批准/退回。批准开通申请本身不安装凭据；实际渠道状态由系统自动检查真实官方接口，申请处理不作为健康凭证。系统管理员可在“官方发送账号 → 官方渠道运行状态”查看检查时间，并独立暂停或恢复新发送；系统恢复连接不会解除人工暂停。
