# 手机资源与学校目标群

手机是平台共享资源，学校通过本校独立目标群的设备绑定参与业务。无需选择旧发送账号，不按责任人学校角色推导手机身份或能力资格。

学校管理员维护群名称、可用状态、共享绑定与任务确认；平台人员按授权维护手机与群的绑定，以及该设备的搜索名称覆盖。下发搜索文字来自默认群名或绑定覆盖名，只使用第一个群搜索结果。手机共享不会开放跨校消息或证据。

平台管理员在“手机设备 → 全平台资源维护 → 业务能力开通”登记配对手机、核对在线、查看通用能力办理与自动检查状态。详见[维护手册](../platform-admin/devices-and-accounts.md)。旧高级适配入口进入当前能力页，历史 v5 单独只读。

当前共享发送使用 v9；在线、本机同意或检查通过均不单独等同于可发送，还需政策、能力和本校业务范围、有效任务确认。官方企业微信客户群及群发继续独立使用。
