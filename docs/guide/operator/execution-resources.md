# 手机设备与发送账号

入口位于 **业务功能 → 手机设备** 和 **业务功能 → 发送账号**，是两个独立页面。

## 当前学校使用资源

运营人员和学校管理员选择当前学校后，只能看到通过本校执行分配关联、设备账号绑定仍有效的资源。负责人拥有学校权限并不意味着该负责人的所有手机都会显示；未分配、分配停用、绑定变更或负责人学校管理员授权失效时不会继续展示。

设备页显示设备名称、绑定账号、控制连接状态与最近心跳；账号页显示账号、企业及使用设备。页面定时刷新，刷新失败或数据过期时不能据此判断设备仍在线。配置可用也不代表允许立即发送，实际任务仍须业务授权与人工确认。

学校管理员通过“配置本校执行关系”进入“手机发送任务 → 本校执行配置”。运营人员没有配置权限时联系学校管理员。暂无资源时先检查分配关系，不应重复登记设备。

## 发送账号 {#sending-accounts}

发送账号指手机中用于业务发送的真实身份。它与“系统功能 → 登录账号管理”中的管理端登录账号用途不同；本页不显示登录凭据、设备令牌或跨校资料。

## 全平台资源维护

平台管理员可在页面顶部切换“全平台资源维护 / 当前学校使用资源”。全平台模式用于登记、配对、绑定与维护，由平台管理员操作；功能移入业务区不会授予普通业务人员这些维护权限。查看学校模式仍须具备该校管理员或运营授权。

全平台设备页通过“高级适配”进入流程与适配维护。详细准备步骤见[资源维护手册](../platform-admin/devices-and-accounts.md)。
