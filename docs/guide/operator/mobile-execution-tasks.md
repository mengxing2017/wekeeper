# 手机任务预览与确认

业务区的“手机任务”用于安排手机独立目标群，与“官方客户群”和原有企业微信群发分别管理。

**当前版本只支持任务登记和手机预留，尚不能启动手机发送。** 请勿把任务已登记、配置准备完成或控制连接在线理解为消息已发送。

## 操作顺序

1. 选择本校授权手机。没有手机时联系平台管理员在“学校设备授权”授予本校使用权；平台管理员代办学校任务也需要本校业务角色。
2. 检查执行配置。无配置、手机尚未接受学校用途、流程未发布或现场验证失效时，按页面说明到手机或“手机执行配置”完成准备。运营人员可以查看配置，维护配置需要学校管理员。
3. 在该手机的有效绑定目标中搜索、多选。“选择本页”只选择当前页，最多 20 个；跨页保留已经选择的目标，不会自动选择该手机全部目标。清空、移除及上下移动只修改本次选择。实际数量还受流程更小预算约束。
4. 填写消息正文，不超过 4000 UTF-8 字节；汉字通常占多个字节。正文空格、换行按原文保留。
5. 点击“预览全部目标和正文”。预览列出全部目标、执行顺序、下发群名原文、正文、群间最短间隔及确认版本。平台只按搜索文字在群分类中取视觉顺序第一项，请先维护并现场核实手机内群名备注；平台不识别真实群身份、真实登录账号，也不保证送达。
6. 本校管理员逐项核对，勾选已核对，再点击“确认任务”。运营人员只能预览，需要管理员自行重新预览和确认。预览 10 分钟后过期；定位、授权、绑定或执行配置变化会使旧预览失效。确认时平台重新检查，并非仅凭页面勾选发放发送许可。

确认会原子登记任务及各目标执行项，并预留这台物理手机。同一手机即使被多个学校授权，也只能被一个任务占用。

## 请求结果不明时

确认遇到网络异常，使用“重试同一次确认”，保持同一预览和幂等键，不会因重试新增第二个任务。若首次确认请求已经发出，即使预览计时结束，仍可重试查询同一次确认结果；如果原请求未成功且预览已过期，服务端会要求重新预览。

关闭预览或离开页面不会取消可能已经登记的任务。先刷新任务记录核实结果，不要连续创建新的任务。切换学校或权限变化后不会继续展示、确认旧学校的草稿和弹窗。

## 阻塞与处理

| 页面提示 | 下一步 |
| --- | --- |
| 手机已有任务占用 | 处理原任务；其他学校的占用联系平台管理员协调，不显示其他学校任务内容 |
| 目标已有待执行或待核对项 | 在任务记录处理原任务；结果不确定先核对，不通过换设备重复安排 |
| 没有可用目标 | 联系学校管理员在“手机目标群”新增并绑定；有搜索条件时也可调整搜索 |
| 目标停用、解绑或授权变化 | 刷新目标，检查绑定和学校设备授权，重新预览 |
| 预览过期或执行版本变化 | 关闭预览，重新检查并生成完整预览，不沿用旧确认 |
| 取消失败，状态或版本变化 | 刷新任务记录；不能通过取消未领取任务清除已发调用或不确定结果 |

## 任务记录

任务记录显示原计划和每目标状态，即使当前目标后来改名，历史仍显示确认时的下发群名及正文。“设备报告已发”只表示设备观察，不代表消息送达。统计分别展示报告已发、确定未发/失败、未执行、等待回报和待核对，不把部分完成表示为全部成功。

当前可由本校管理员或运营取消 queued 且全部目标仍为 pending 的任务。页面显示“取消未领取任务”后还需再次确认；服务端重新核实状态，成功后释放手机预留。普通取消不处理已领取、已准备、已发调用或 unknown；不确定结果不能自动重发。后续领取、发送、用量及人工核对链路尚未开放。
