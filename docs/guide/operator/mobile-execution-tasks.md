# 手机群消息两步发送

进入“手机任务 → 手机共享发送”。先在本校使用管理开通手机和目标群；范围尚未批准时办理学校使用授权；离线、锁屏或本地准备失败时由平台在授权候选内继续调度。平台不管理手机 UI 规则，手机适配问题不阻止创建、预览和确认任务。手机领取业务意图后自行识别页面和准备正文，准备成功才申请单次许可；不支持或准备失败须回报该次未执行原因，不要求平台安装手机规则包。

1. 按执行顺序选择本校目标群，输入完整文字，点击“预览逐群执行计划”。系统自动保存草稿；不选择研发阶段，也无需另点保存。
2. 核对完整文字、唯一目标群名和全部授权候选手机，点击“确认发送”。这是实际发送确认，不再重复勾选相同确认框。所选手机为首选；同时确认本群全部有效授权候选，首选不可用时系统自动换机。

文字的有效空格和换行保留。预览后修改文字、群或间隔须重新预览；候选范围内自动换机记录完整轨迹，不重复确认；正文、目标或授权范围变化需重新预览确认。

详情保留逐群状态、停止、人工核对和改派。停止会撤销后续执行资格，手机在本地安全检查点停止。当前手机离线、明确失败，或接收任务后 5 分钟仍无最终结果，平台自动选择下一台合格手机。unknown 保留历史证据和风险记录，但不阻止超时切机；切机可能造成重复发送。旧任务确认到期后须复制为新意图再确认，续期使用授权不会延长旧任务。

不同目标独立调度，遵守确认的业务间隔；某群或手机故障不拖住无关目标。原手机结算只影响该手机资源。手机使用者只负责托管授权、解锁、系统权限和后台连接。


## 任务是否已经到达手机

确认后在任务详情区分两个状态：

- **平台已创建，等待手机同步**：任务已入库，平台还没有收到手机持久化成功后的接收记录。设备在线本身不代表已经收件。
- **手机已接收，等待执行条件**：手机已保存任务摘要。接收记录不代表已发送。新任务同时显示目标调度状态、授权候选和自动换机历史；原手机故障时不要求手工重新提交。

手机“任务”页面提供“已接收任务”和“最近结果”，未领取的后续群也会显示学校、群名及任务中的顺序。点击“刷新任务”仅更新列表，不会确认发送或启动企业微信。列表读取独立于无障碍、解锁和执行恢复；断网时保留上次任务并标记过期，首次同步失败不显示为空任务。

手机自动补报接收状态，不需要使用者逐任务确认。接收补报失败会后台重试，不会阻止正常领取或发送。仍需通过原有托管、学校确认和执行条件才能实际执行。

### 下发失败与轮次上限

每个目标最多完整遍历授权候选手机 3 轮（包含首次），每轮至少等待 5 分钟。只有一台手机且一直无反馈时，三轮约 15 分钟（另加扫描及领取延迟）；已领取任务不会因心跳暂时过期或暂停而提前结束本轮。第三轮全部候选失败或不可用后，显示“任务下发失败”，停止该目标的自动下发；其他目标继续独立调度。未领取分配超过 5 分钟或已接收后 5 分钟无最终结果会切换候选，业务间隔等待不消耗轮次。

手机上线、页面刷新、服务重启和人工改派均不能重置耗尽预算。再次发送请复制原意图为新草稿并重新确认。历史结果未知不表示确定未发送，迟到结果仍会记录，迟到成功可修正目标结果。

所有目标结束后，任务详情停止自动轮询；可点击“刷新任务结果”查看迟到结果。仍有活动目标时继续自动更新。

任务列表直接显示平台汇总状态，无需先打开逐群进度：全部目标已发送显示“任务已完成”，手动停止未完成任务显示“任务已手动停止”，三轮耗尽显示“任务已停止自动下发：三轮下发失败”。仍有目标执行时显示“任务正在调度”。完成结果优先于停止标记，完成后再停止或停止后补报全部成功，都保留“任务已完成”。
