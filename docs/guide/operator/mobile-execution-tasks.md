# 手机任务

手机共享发送按学校目标群组织，手机属于平台共享资源池。历史手机发送功能未上线、没有业务数据，历史任务导航与旧任务查询/取消入口已移除，不需要迁移或核对旧任务。

## 操作流程

1. 学校管理员维护本校独立目标群，平台为具体群绑定共享手机，并完成匹配的能力开通、手机同意和无发送检查。
2. 运营人员选择目标群、填写正文并保存草稿，预览每个群的共享手机和实际搜索文字；需要调整分配时重新预览。
3. 学校管理员核对预览并明确确认。后台资格、执行时段、额度和手机状态均满足后才可领取。
4. 在任务详情查看逐群进度，必要时停止任务。unknown 必须人工核对，不得自动重试；确未发送且具备改派资格时，重新确认改派。

配置和代码就绪不代表真机验收完成。没有匹配发行、有限验收范围、有效手机同意或逐群检查时保持阻断。观察到已发送只代表手机界面证据，不代表接收方送达。

企业微信官方客户群群发继续独立使用，不依赖手机绑定。工程配置与验收步骤见[手机共享发送运行手册](../../runbooks/shared-mobile-send.md)。
