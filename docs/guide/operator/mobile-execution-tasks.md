# 手机群消息两步发送

进入“手机任务 → 手机共享发送”。先在本校使用管理开通手机和目标群；范围尚未批准时办理学校使用授权；手机离线或未解锁时按手机状态处理。平台不管理手机 UI 规则，手机适配问题不阻止创建、预览和确认任务。手机领取业务意图后自行识别页面和准备正文，准备成功才申请单次许可；不支持或准备失败须回报该次未执行原因，不要求平台安装手机规则包。

1. 按执行顺序选择本校目标群，输入完整文字，点击“预览逐群执行计划”。系统自动保存草稿；不选择研发阶段，也无需另点保存。
2. 核对完整文字、群顺序、实际搜索名和候选手机，点击“确认发送”。这是实际发送确认，不再重复勾选相同确认框。离线手机可选择，静态范围有效时可先确认等待。

文字的有效空格和换行保留。预览后修改文字、群或间隔须重新预览；条件变化不会静默换机。再次发送须重新预览并明确确认。

详情保留逐群状态、停止、人工核对和改派。停止只阻止新许可。unknown 保持风险并等待真实证据核对，不自动重发。旧任务确认到期后须复制为新意图再确认，续期使用授权不会延长旧任务。

前群结果落账、原手机确认空闲、间隔结束后才执行下一群。手机使用者只负责托管授权、解锁、系统权限和后台连接。


## 任务是否已经到达手机

确认后在任务详情区分两个状态：

- **平台已创建，等待手机同步**：任务已入库，平台还没有收到手机持久化成功后的接收记录。设备在线本身不代表已经收件。
- **手机已接收，等待执行条件**：手机已保存任务摘要。下方继续显示实际等待原因，例如前群尚未结束、手机锁屏或连接待恢复；接收记录不代表已经发送。

手机“任务”页面提供“已接收任务”和“最近结果”，未领取的后续群也会显示学校、群名及任务中的顺序。点击“刷新任务”仅更新列表，不会确认发送或启动企业微信。列表读取独立于无障碍、解锁和执行恢复；断网时保留上次任务并标记过期，首次同步失败不显示为空任务。

手机自动补报接收状态，不需要使用者逐任务确认。接收补报失败会后台重试，不会阻止正常领取或发送。仍需通过原有托管、学校确认和执行条件才能实际执行。
