# 手机任务

手机业务正在切换到“群属于学校、手机属于共享资源池”的模型。当前页面保留本校历史任务、原计划和逐群结果；旧的先选手机、学校授权及确认即长期预留流程已停止，新版任务确认尚未开放。

目前可以由学校管理员维护手机目标群，并联系平台资源维护人员为具体群绑定共享手机。同一个群可以绑定多台候选手机，各手机可使用不同的覆盖搜索名；新增群和绑定手机不会自动发送。

历史任务可以查看原搜索文字、原正文及逐群状态。只有整个任务尚未领取时可以普通取消；调用已发或结果不确定的项目不能通过普通取消解除风险。“设备报告已发”不代表消息送达。

新版将先按群选择，再逐项预览手机与有效搜索文字，人工确认后排队，实际领取时才占用手机。确认后离线不会静默换机；必须在可以证明未发送的前提下重新预览并确认改派。相关执行链路验收完成后再开放。

原有企业微信官方客户群和群发继续独立使用，不通过手机共享绑定取得权限。
