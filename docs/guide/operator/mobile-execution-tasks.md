# 手机共享发送任务

进入“手机任务 → 手机共享发送”，与企业微信官方群发区分使用。先由平台完成共享资格、通用能力和本校业务范围，学校维护目标群与手机绑定。

1. 按实际执行顺序选择本校目标群，必要时用“前移”调整；输入完整文字、限定测试/生产阶段和逐群间隔。有效空格与换行保留。
2. “保存草稿”后“预览逐群执行计划”，查看群名、真实搜索文字、手机及阻塞原因。已绑定手机离线、待本人授权或缺权限时仍可选；下拉框可选不等于已可执行。
3. 学校管理员明确勾选核对并“确认进入共享发送队列”。发行、政策、业务范围及无风险等静态资格必须满足；仅缺运行条件时可以确认等待，手机恢复后按原意图继续，不静默换机。
4. 状态变化后可“更新预览并重新确认”。修改文字、群序、阶段或间隔要先保存；新预览清除旧勾选。确认到期不再发许可，可在详情复制原意图为新草稿并重新确认。
5. 详情查看每群和每次尝试。停止阻止新许可但不撤回已有调用；`unknown` 必须凭真实证据核对，不能仅凭等待超时断言未发送。改派须原设备已静止，且原尝试已确认未发送或调用前失败。

逐群顺序跨手机保持一致：前群结果落账、原手机确认回执与界面空闲、间隔结束后才开始后群任何搜索/检查。实际间隔取学校设置、人工基线和新旧有效政策的最大值；可以延长。

无需输入外部群 ID，无需先上报企业微信版本或安装环境。失败时通过“申请适配支持”联系平台办理；手机使用者负责本人同意、解锁、通知、无障碍和后台连接。
