# 手机任务与学校目标群

学校管理员维护本校独立目标群，平台将共享手机与群绑定。手机不归属于学校，不要求维护发送账号、学校专属流程、人工计时或旧 v5 授权。平台管理员身份不代替学校业务权限。

## 当前可用与阻塞

目标群、设备绑定、能力开通与不发送消息的现场检查已分开管理。当前共享执行链路尚未完成，`execution_ready=false`；创建界面或能力同意不能被理解为手机已经能发送。页面会显示具体阻塞和负责方，不通过旧 v5 继续发送。

完整发送上线仍需固定版本与搜索文字、预览、人工确认、设备跨校串行和限流、单次许可、逐群回报及真机验收。搜索文字取目标群默认名称或该设备绑定覆盖名，每项只处理搜索结果中的第一个群；不要求同名结果唯一。

历史已调用、unknown 与核对记录保留。结果不明不能换手机重建任务或自动重试；联系学校管理员核对原记录。旧任务的停止、补报与核对不授权新增发送。

手机现场人员负责保持托管连接、权限与解锁，并在原生窗口明确确认限定用途和现场检查。检查不会输入消息或点击发送，不在后台自动运行界面。
