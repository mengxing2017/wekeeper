# 客户群与消息模板

适合系统管理员。系统管理员选择已核实目录群，发送时核验真实群主及发送资格。

## 客户群

入口：“企业微信 → 客户群”。这份列表属于全局，不等于系统同步出的所有客户群。

1. 核对资源，在客户群配置中查看已有关联。
2. 分发管理员从候选目录选择群，再核对官方群名、群主及是否已经关联。
3. 填写系统中使用的显示名称，确认“关联到全局”。完成后检查全局列表中出现该群。
4. 候选为空时，请系统管理员检查通讯录和客户群同步；分发管理员还应检查自己的企业成员绑定及是否是群主。

已经关联为分发目标的群不会重复创建。数据变化时刷新重选。

## 消息模板

入口：“企业微信 → 消息模板”。同页编辑名称、正文和业务字段，选择全局真实内容或明确的示例进行预览，再点击“确认发布模板”。版本由系统自动保存，历史按发布时间、发布人和说明展示。

“保留草稿”不改变正在使用的发布正文。并发修改或预览过期时重新核对，不覆盖别人的修改。创建任务时按名称及发布时间选择模板，并检查完整替换结果。

修改模板不会自动修改已确认任务。不要把尚未发布的草稿当成业务默认版本；无模板的直接文本官方群发，仍需全局管理员确认。

## 完成后

应能在全局客户群列表找到目标群，并在任务预览中看到正确正文。如果群不存在、已失效或正文不正确，停止确认并联系管理员。

下一步：[官方群发](broadcast-tasks.md)或[手机发送](mobile-execution-tasks.md)。手机目标群还需维护真实界面可见身份，不能只凭官方群标识定位手机页面。
