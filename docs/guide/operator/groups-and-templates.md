# 学校客户群与消息模板

适合准备学校运营内容的运营和学校管理员。客户群关联需要满足学校管理与群主条件；运营没有关联权限时请学校管理员处理。

## 学校客户群

入口：“企业微信 → 客户群”。这份列表属于当前学校，不等于平台同步出的所有客户群。

1. 核对学校，在客户群配置中查看已有关联。
2. 学校管理员从候选目录选择群，再核对官方群名、群主及是否已经关联。
3. 填写学校内使用的显示名称，确认“关联到当前学校”。完成后检查本校列表中出现该群。
4. 候选为空时，请平台管理员检查通讯录和客户群同步；学校管理员还应检查自己的企业成员绑定及是否是群主。

已被其他学校关联的群不会作为可选候选。数据已变化时刷新重选，不复制群标识手动绕过冲突。

## 消息模板

入口：“企业微信 → 消息模板”。先确认模板用途，再编辑正文并保存版本，需要使用时按页面要求发布。创建任务时选择已发布版本，在预览中读完整正文，确认替换结果与学校一致。

修改模板不会自动修改已确认任务。不要把尚未发布的草稿当成业务默认版本；无模板的直接文本官方群发，仍需本校管理员确认。

## 完成后

应能在本校客户群列表找到目标群，并在任务预览中看到正确正文。如果群不存在、已失效或正文不正确，停止确认并联系管理员。

下一步：[官方群发](broadcast-tasks.md)或[手机发送](mobile-tasks.md)。手机目标群还需维护真实界面可见身份，不能只凭官方群标识定位手机页面。
