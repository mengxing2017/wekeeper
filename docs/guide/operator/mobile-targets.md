# 手机目标群与候选绑定

系统管理员在“手机目标群”新增、修改、停用目标。业务只填写一个群名称，不填写完整群名、搜索词、别名或设备覆盖文本。

同名不代表同一真实群。新增同名目标需确认“仍作为独立目标新增”，不会自动合并已有记录。

“共享手机与目标群绑定”按真实设备与目标建立候选关系，同一目标可绑定多台手机；所有候选使用同一个业务群名。停用某个绑定不删除目标，也不影响其他有效绑定。

手机和目标全局管理，不办理工作空间或成员授权。已有使用管理授权的资源仍受期限、暂停、撤销和额度限制；绑定不能绕过这些约束。

创建任务时确认正文、目标和授权候选集合。所选手机为首选，系统仅在确认的候选内换机，不因新增绑定扩大已确认任务范围。
