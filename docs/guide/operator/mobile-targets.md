# 手机目标群与设备绑定

手机目标群与原有企业微信官方客户群分别管理。维护这里的目标不会修改官方客户群，也不会创建官方群发任务。

## 填写目标

学校管理员在“业务功能 → 手机目标群”中选择“新增目标群”。

- **下发群名**：手机内实际使用的群搜索文字，可以填写现场维护的群名备注。内部空格、大小写和符号会原样保存，请移除首尾空白和换行。
- **平台别名**：供管理人员区分目标，不参与手机搜索。
- **管理备注**：供管理人员说明用途，不参与手机搜索。
新增目标群后，请联系平台资源维护人员绑定共享手机；学校不再自行绑定设备。

同校已存在相同搜索文字时，需要确认“仍作为独立目标新增”。同名不代表同一真实群，新增记录不会自动合并。

设备执行时只应选择群分类中第一个搜索结果。请先在手机现场维护易于区分的备注，平台不能证明真实群身份或证明手机已经加入该群。

## 维护绑定

“共享手机与目标群绑定”只读展示本校群的手机及有效搜索文字。平台人员可独立停用每个绑定，不删除目标，也不影响其他设备或其他学校。

群归属学校，手机是跨学校共享资源。同一群可绑定多台候选手机；不同手机群备注不同时，可由平台在绑定设置覆盖名，否则继承群默认名。学校管理员维护群，学校人员只读绑定；平台资源角色不能代替学校角色确认任务。

修改下发群名或启停后，应重新核对执行范围；只修改别名、备注不会改变搜索文字。归档后的目标不再作为新任务候选，官方客户群不受影响。

当前独立目标资源用于 v9 手机共享发送，不能当作旧任务或官方群发中的目标使用；仅新增目标或绑定手机不会自动发送。

## 共享设备池与自动检查

平台一次批准本校可使用的手机后，管理员在“共享手机与目标群绑定”选择本校目标群和可用手机即可。仅在手机中的实际群名不同于目标群默认搜索文本时填写覆盖文本。停用学校自行创建的绑定不删除目标群，也不影响其他学校。

手机持有人首次在 keeper-otter 启用一次托管，后续群检查由后台自动执行。页面显示手机授权、连接、业务范围、解锁、权限和自动检查状态。“重新评估自动检查”是诊断及重试入口，不是每次发送前必点步骤。离线恢复、正常令牌刷新和适配更新不需要重新同意；撤回或重新配对后需本人重新授权。

发送由管理员核对预览并确认，不办理研发验收、发行或测试/生产放行。
