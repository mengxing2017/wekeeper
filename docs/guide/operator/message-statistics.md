# 统计概览

系统管理员登录后默认进入“统计概览”。该入口位于导航最顶部，点击顶部 WeKeeper 品牌也可返回；直接打开消息或任务链接时保留指定页面。

## 查看消息量

首页展示今日、本周、本月和本年的接收消息数，与前期相同进度比较。时间采用北京时间（Asia/Shanghai），一周从周一开始。相同事件原文重复投递只计一条；接收成功不表示已经发送。

四张周期卡片随来源平台、业务单位、路由和来源方式变化，不受发送通道、客户端及主图日期影响。手动任务不产生来源收件。

“接收趋势”支持小时、日、周、月、年统计和日期范围。没有记录的时间桶显示 0；过大范围需改用较粗粒度。图形下方提供相同数据的周期表。

## 查看发送结果

“发送分析”区分企业微信官方通道、手机企业微信和手机个人微信。同一来源消息可能使用多个途径，各途径的来源消息数不能直接相加。

- 群目标按通道和群身份计数，换手机不增加目标数，同名官方群与手机群不合并。
- 全部手机模式下，一个群目标对应多项独立执行责任，全部责任成功后群目标才成功。
- 成功、失败、未知、处理中分别列出。成功/全部目标与成功/明确结果采用不同分母；没有分母时显示“—”。
- 手机接收任务和官方任务创建均不等于发送成功；发送成功也不代表群成员已读。

“业务单位”按接收时或任务确认时的单位归属分析。未关联单位的手动任务单列，不需要创建默认单位或工作空间。停用单位和归档目标的历史记录仍保留。

## 核对异常

“失败与核对”分别查看未下发消息、最终失败目标和未知目标。点击数量或原因可打开明细，再进入实时消息或任务查看证据。

设备离线、未调用或超时只解释对应尝试，换机成功后不计为最终失败目标。历史未知风险与当前未知结果分开，风险数量不能与失败相加。

“当前关注”覆盖筛选范围内所有尚未结束目标，不限主图所选日期。目标范围尚未完整时，页面会提示，不能据已有少量成功目标判断整条消息全部成功。

## 刷新与导出

页面在前台每 60 秒刷新，打开统计明细时暂停自动替换版本。汇总 CSV 包含筛选、指标版本、时区和统计时间，不含正文或授权凭证。

明细与导出校验原查询版本。如果业务结果已经变化，提示同步刷新后重新查看；统计快照 30 分钟后过期。原业务详情显示实时状态，可能比统计结果更新。

统计查询失败不改变消息受理、调度和发送，可通过其他导航继续业务。所有统计查询、明细及导出均要求有效的系统管理员身份，不要求选择工作空间或企业微信认证。
