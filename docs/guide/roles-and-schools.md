# 角色、学校与菜单权限

适合所有使用者。开始前先打开账号菜单，确认身份，再核对页面“当前学校”。

| 身份 | 主要工作 | 遇到权限问题联系谁 |
| --- | --- | --- |
| 平台管理员 | 管理账号、学校、通讯录、群目录和全平台设备 | 系统部署或平台维护负责人 |
| 学校管理员 | 维护已授权学校的设置，准备本校业务并确认需管理权限的操作 | 平台管理员 |
| 运营 | 处理已授权学校的内容与运营工作 | 学校管理员或平台管理员 |
| 普通成员 | 在已授权范围使用社区 | 学校管理员 |

## 如何核对

1. 先确认学校名称，避免把同名内容或群配置到另一所学校。
2. 进入“学校成员与权限”查看当前学校成员与角色；学校授权由平台管理员维护。
3. 需要变更授权时，提供账号名称、学校名称和工作职责，由平台管理员在账号/学校成员入口处理。
4. 授权更新后刷新页面，重新检查学校和菜单；若仍报权限错误，将错误文字交给管理员核对。

学校管理员可查看本校成员，不应据此认为自己可以授予平台权限。平台管理员能进入管理页，也不能用平台身份替代业务接口要求的学校身份。直接文本官方群发确认需要本校管理员授权。

完成后，你应能说清“用哪个账号、在哪所学校、以什么角色操作”。不需要也不应修改浏览器请求或学校标识来绕过授权。
