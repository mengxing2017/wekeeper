# 页面名称、术语与状态

适合看不懂菜单或结果的使用者。阅读任务结果前，先核对自己使用的发送方式。

| 名称 | 实际含义 |
| --- | --- |
| 企业通讯录 | 企业微信应用可见的内部成员和部门，不是全部企业成员的保证 |
| 客户群总览 | 平台从企业微信读取的群目录、统计和同步任务 |
| 客户群 | 学校关联的客户群，决定学校可以选择的范围 |
| 模板版本 | 已保存或发布的一份正文规则；后续修改不能改写已确认任务 |
| 登录账号 | 使用浏览器后台的人 |
| 发送账号 | 在手机或官方通道中实际发送的业务身份 |
| 手机配对 | 将独立执行端登记为本系统设备；不是已经确认发送 |
| 已分配流程 | 学校为设备和账号选择了已发布流程，随后才可在配置消息中选择 |
| 已确认 | 人已核对并提交本次任务，不等于发出消息 |
| 已创建，等待成员执行 | 官方任务已经创建，需要执行成员到企业微信中继续完成 |
| 离线，任务可排队 | 可保存任务，但手机恢复连接并满足条件后才能执行 |
| 结果不确定 / unknown | 无法确定是否已产生外部效果，必须核对，不能当作未发送 |
| 停止 | 阻止约定范围的后续工作，不撤回已经发送的消息 |
| 快照 | 一次完整成功同步的目录数据；同步失败不意味着可以清空旧数据 |
| 凭据代次 | 服务端企业微信配置的一次版本；更换凭据后旧数据需要重新核验 |

## 如何判断是否完成

不要只看一个绿色提示。先看任务详情、逐群状态、最后同步时间和证据来源。官方结果与手机报告的含义不同，查看[结果与异常处理](operator/results-and-recovery.md)。

如果仍不能判断，保存任务名称、发生时间和错误文字交给管理员；不要附上密码、令牌、完整聊天内容或未脱敏截图。
