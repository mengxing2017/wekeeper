# 全局分发权限与执行授权

当前后台由系统管理员统一管理企业微信和手机分发资源，不创建、选择或授权工作空间。账号必须启用，并通过服务端全局管理员校验；没有管理员权限的登录账号不能访问分发管理接口。

客户群、任务、手机目标与设备绑定按真实资源身份管理。企业微信仍核验官方成员、群主、企业权限及发送资格。手机仍核验设备与目标绑定、确认的候选集合、使用期限、次数与预算根；续期或调整不能重置已消耗额度。

手工任务由管理员核对正文、目标和候选范围后逐任务确认。系统只在已确认候选中调度和换机，不因全局管理扩大已确认范围。设备一次接收完整签名执行包，直接本地执行并补报真实结果。

## 通道接收配置

两类接收配置按业务单位维护目标和发送资源。业务单位用于消息路由，不是账号权限分区，也不会自动创建工作空间。管理员启用配置时授予后续新消息的链路授权；自动任务记录真实服务执行身份。

无目标或资源的消息记录未下发成功，补配置只影响新消息。同一消息同一通道不重复投递。广告按业务单位、平台或全局绑定，轮询进度按业务单位记录。

## 操作与审计

创建人、确认人、执行人和操作对象继续记录。操作审计属于系统管理，仅系统管理员可查询。资源自身停用、暂停、撤销和期限分别生效，不存在空间停用或成员授权门槛。
