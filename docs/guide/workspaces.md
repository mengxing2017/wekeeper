# 独立分发工作空间与授权

企业微信分发与移动端分发分别管理自己的工作空间、目标和权限，不依赖论坛学校。一个账号可以获得其中一种或两种分发授权，两类权限不会互相授予。

| 身份 | 权限 |
| --- | --- |
| 系统管理员 | 创建分发工作空间、维护分发授权、管理系统目录和共享手机 |
| 分发管理员 | 管理获授权工作空间的目标并确认发送 |
| 分发运营 | 查看获授权工作空间，准备任务 |

企业微信的客户群、消息模板、群发任务和发送账号页面直接显示当前业务内容，不展示工作空间下拉框。有多个企业微信工作空间时，获授权成员在“工作空间与权限”列表的对应行点击“使用此工作空间”；后续业务页面沿用当前范围。在“手机任务 / 手机目标群”选择“移动分发工作空间”，两类分发范围独立。

系统管理员在“企业微信分发管理 → 工作空间与权限”新建企业微信工作空间，在列表对应行点击“分发权限”维护该工作空间的成员。移动工作空间仍在“手机任务 / 手机目标群”页面新建，并通过“移动分发权限”维护成员。授权时按已有登录账号的用户名授予管理员、运营，或撤销该分发授权。授权只作用于当前通道、当前工作空间。变更后刷新核对；撤销后服务端拒绝后续受保护操作，在途任务继续遵守原有执行与审计规则。

企业微信还需核验真实企业成员绑定、群主、发送资格与官方权限；移动端另有业务使用范围、设备和目标绑定。工作空间授权不能代替这些条件。

学校成员与权限、学校设置、学校管理、登录账号管理已迁出 wekeeper，由独立论坛 linjian 承接。wekeeper 保留现有分发账号登录、会话、个人资料和系统管理员新增、查询、编辑、删除与密码维护，不同步两边学校或账号变更。分发继续使用保留的现有账号；首次系统管理员由部署负责人使用现有 CLI 初始化。

升级会一次性保留原范围及成员授权，学校名称可能作为原工作空间名称显示。此后新建工作空间无需学校，学校停用或成员变更也不会改变分发授权。
