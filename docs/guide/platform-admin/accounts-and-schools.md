# 账号、学校与授权

适合平台管理员。入口：“平台管理 → 学校管理 / 账号管理 / 本地管理员管理”。开始前准备学校名称、人员职责与需要授予的学校范围。

## 按顺序准备

1. 在“学校管理”点击“新建学校”，核对名称与启用状态。打开学校详情进入该校配置或成员管理。
2. 在“账号管理”点击“新建账号”，准备登录账号、显示名称及初始密码，并安全交给本人。
3. 在学校成员或账号授权入口，选择明确学校与角色：日常运营授予运营，需要本校管理与确认职责时授予学校管理员。
4. 确认账号有效，并让本人登录后核对当前学校和菜单。
5. 涉及企业微信身份时，先同步通讯录，再从明确成员中选择绑定。核对姓名和 UserID，不能通过相似昵称猜测身份。

## 三种身份不要混淆

“本地管理员管理”维护已有平台管理员状态和登录密码；不是学校管理员列表。首次平台管理员由部署负责人通过 CLI 初始化，见[部署手册](../../runbooks/docker.md)。

学校角色要单独授予。企业成员绑定只是身份映射，不能代替学校授权。手机发送账号另在“手机设备与发送账号”维护，不能用后台账号名称代替真实可见身份。

## 完成与撤销

完成后本人能登录正确学校。人员离岗时按实际需要停用账号、撤销学校角色并核对在途业务；不要删除历史任务和审计来处理离岗。版本冲突时刷新后重选。
