# 系统管理员维护

入口：“系统管理 → 系统管理员”。本页用于维护 WeKeeper 分发系统的管理员账号，列表显示账号、姓名及启用状态。

## 查询、新增与编辑

- 在查询框输入账号或姓名，点击“查询”；点击“重置查询”恢复完整列表。
- 点击“新增管理员”，填写唯一账号、姓名和 12–128 字节的初始密码，保存后即可登录。
- 点击管理员行的“编辑”，修改姓名或启用状态。账号创建后不可修改。
- 停用账号会立即注销该账号的所有会话；再次启用后可重新登录。当前登录管理员不能停用自己。

## 删除管理员

点击对应行的“删除”，核对账号后确认。删除会撤销管理员身份、停用账号并注销所有会话，保留历史任务和审计记录。已删除账号不再显示在管理员列表中，原账号名仍被保留。当前登录管理员不能删除自己，以确保系统始终有可用管理员。

新增、编辑和删除操作会写入操作审计，仅系统管理员可以执行。

## 重设管理员密码

1. 找到需要维护的管理员，点击“重设密码”。
2. 输入至少 12 个字符的新密码，点击“确认重设密码”。
3. 重设成功后，该账号的所有现有会话失效；重设当前登录账号时，页面返回登录界面，需要使用新密码重新登录。

首次管理员由部署负责人通过服务端 CLI 初始化，见[部署手册](../../runbooks/docker.md)。

系统管理员负责两类独立分发工作空间、分发授权、企业微信目录和共享手机的系统维护。具体工作空间内的业务操作仍需按通道核验权限，见[工作空间与授权](../workspaces.md)。企业成员绑定与官方发送资格需单独核验。
