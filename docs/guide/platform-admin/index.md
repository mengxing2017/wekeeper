# 平台管理员上线清单

适合系统管理员。开始前由部署负责人完成 API、数据库、Web 和首次管理员初始化；步骤见[Docker 手册](../../runbooks/docker.md)。

1. 使用本地管理员账号登录，核对站点与环境，生产操作前确认备份策略。
2. 在“学校管理”创建或核对学校；在“登录账号管理”准备人员并授予学校角色。
3. 核对企业微信服务端配置，在“企业微信集成”完成同步并检查成员范围。
4. 在“客户群总览”同步群目录，交学校管理员关联本校群。
5. 需要手机发送时，登记手机、配对并核对真实发送账号；由专门维护人员准备真实验证发布的流程。
6. 由本校管理员确认发送范围与历史未决任务，再开放业务。
7. 让业务人员按[每日清单](../operator/index.md)在隔离测试学校走通流程，完成交接。

完成后应有“人员—学校—权限—群—发送方式—结果负责人”的明确对应，不只以服务启动成功作为交付标准。
