# 手机接入与使用开通

手机是系统共享资源，可服务不同工作空间，工作空间只查看当前工作空间范围和消息。

登记手机并生成配对码，现场人员在 keeper-otter 完成配对、首次启用托管，设置通知、无障碍和后台连接。持续在线与手机解锁由现场人员维护。

系统在[使用管理](shared-mobile-resources.md)两步开通工作空间的手机和群范围。手机不需要按工作空间或群重复同意。本人撤回、重新配对或实质扩权时重新确认。

申请待批准、手机离线、等待本人授权及检查失败分别显示原因。研发交付、发行激活及验收不属于业务办理步骤。原有结果补报和 unknown 核对保留，不通过清库或重新配对跳过未决结果。


## 设备在线与连接恢复

设备常态每 60 秒维护一次心跳。平台收到有效设备心跳并回复，或收到平台探测对应的设备响应，即立即确认在线。每次成功心跳交互都会更新最新心跳时间，下一次主动心跳从该时间起等待 60 秒；命令回执不计作心跳。系统只保留最新心跳状态，不累计心跳历史。单次回包超时、网络切换或控制连接重建只表示通道需要恢复，不会立即判设备离线。

默认最后一次有效心跳后连续 3 个周期及 10 秒响应宽限均无有效通信，即 190 秒后，才判超时离线。130 秒后可能显示“连接不稳定”，此时尚未离线，不因该提示触发离线换机。设备停用、凭据失效和执行暂停单独显示；设备在线不代表已具备发送条件。页面“状态待刷新”表示页面未取得新快照，不代表设备离线。

暂停托管和恢复托管由手机本人在 keeper-otter 操作，平台不下发暂停或恢复托管指令。平台业务执行设置、使用范围暂停与手机托管状态独立；业务暂停不改变本机托管同意。
