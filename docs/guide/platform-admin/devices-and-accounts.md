# 共享手机资源维护

入口：“业务功能 → 手机设备”。手机是平台共享资源，不归属于学校或发送账号；设备备注中的账号线索不作为授权依据。企业微信官方客户群和官方群发是独立业务，不受手机能力开通影响。

1. 登记手机，在管理端生成一次性配对码，在 keeper-otter 输入；核对服务地址与设备名称。
2. 启用长期托管，检查控制连接、最近心跳、通知与无障碍权限。在线不等于可发送，锁屏时界面操作等待解锁。
3. 进入[业务能力开通](flow-maintenance.md)，由产品提供真实适配，手机明确同意用途与能力范围。不选择试用学校、不登记旧发送账号、不向学校发布流程。
4. 学校维护独立目标群，平台按权限绑定手机与群；设备可参与不同学校的群任务，不能由此看到其他学校正文或证据。

当前共享发送仍被明确阻断，能力同意和现场检查不等于发送上线。历史 v5 只读保留，旧排队验证停止受理；结果补报、取消、撤销与 unknown 核对继续保留。
