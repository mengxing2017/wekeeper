# 企业通讯录与客户群目录

适合平台管理员。入口：“平台功能 → 企业微信集成；业务功能 → 客户群总览”。开始前由部署负责人准备匹配的企业 CorpID、应用 Secret、可信出口 IP 和应用可见范围。凭据只配置在后端。

## 第一次同步

1. 打开“企业微信集成”，检查服务端配置状态，发起完整同步。
2. 等待成功后检查部门、成员和同步时间，确认应用可见范围符合预期。
3. 打开“客户群总览”，点击“同步客户群”，查看同步任务及最近成功时间。空库首次从该页面发起时，会先准备通讯录再继续群同步；通讯录失败时先处理错误。
4. 核对群主、成员数量与核验时间，再交学校管理员在“客户群”关联本校群。

## 同步状态怎样理解

| 提示 | 处理 |
| --- | --- |
| `directory_snapshot_required` | 当前凭据没有完整通讯录快照，先完成通讯录同步再重试 |
| `wecom_60020` | 请部署负责人核对 API 公网出口可信 IP |
| 官方权限错误 | 检查应用权限、可见范围与凭据是否匹配 |
| 保留上次成功快照 | 本次失败，仍显示历史成功数据，不代表这次已更新 |
| 尚无成功快照 | 尚未有完整成功群数据，不能把空列表解释为没有客户群 |
| 超过 24 小时 / 待核验 | 重新同步核验；旧数据可能不进入候选和当前统计 |

凭据变化或可见范围缩小时，先核对原因再确认范围变化；不要用清库或跳过群主来制造同步成功。等待过久时检查任务状态和后端日志，不连续点击创建重复任务。

## 完成后

平台目录出现正确群及新成功时间；学校候选仍受群主、身份、核验状态和跨学校关联限制。学校管理员没有候选时，分别检查企业成员绑定与群主身份。
