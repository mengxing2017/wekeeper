# 共享手机业务能力开通

当前入口为“业务功能 → 手机设备 → 全平台资源维护 → 业务能力开通”。原“高级适配”书签进入同一说明页，不恢复旧 v5 创建与发布表单。

1. 选择共享手机，查看连接、手机环境、适配支持及阻塞负责方。不需要选择试用学校、发送账号或上传 JSON。
2. 有适用产品适配时，发送开通申请，由现场人员在手机原生窗口核对用途并明确同意。环境或配置变化需重新核对。
3. 学校管理员维护本校独立目标群和设备绑定；需要现场检查时，学校发出限定目标的邀请，平台发起检查，手机再次原生确认后执行不发消息的检查。
4. 查看实际检查结果。申请、同意、检查通过和任务发送权限分别展示；当前共享任务执行链路尚未完成，`execution_ready=false`，不能宣称可发送。

产品尚未适配时，提交支持请求交产品研发处理。不得使用示例规则或旧成功证据替代真实适配。
