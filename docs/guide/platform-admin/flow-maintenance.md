# 通用业务能力办理

当前入口为“共享手机与目标群 → 业务能力开通 → 通用能力办理”。平台维护人员使用结构化页面条件、导航步骤和桌面路径表单维护通用流程；普通学校管理员只维护业务群、搜索文字、手机分配、正文和群间隔。

候选维护验证不依赖已激活发行或生产放行。请按[共享发送完整手册](../../runbooks/shared-mobile-send.md)完成真实 APK、人工采样、桌面搜索及全部应用无发送验证、限定首测、发行激活和业务范围。生产验收独立办理，不由历史适配或测试通过自动转换。

未知企业微信版本先使用完整通用流程；失败后才补充最小版本诊断，由平台根据实际界面修复。不得通过要求手机先上报环境来阻断通用执行。

旧 v5/v7/v8 的资料仅供历史查询与原协议收尾，不用于新任务资格。unknown 不清空，不自动重发；旧许可和固定结果保留恢复入口。
