# 操作审计与公共资源

适合平台管理员，以及阅读本校审计的学校管理员和获授权运营。开始前确认学校或平台范围；文档可公开阅读不代表当前账号拥有相应业务权限。

## 查看操作审计 {#audit}

入口：“系统管理 → 操作审计”。按时间和目标记录核对执行人、操作与对象；与原业务任务详情一起阅读。学校用户只能读取其授权学校范围，平台管理员需要进入具体学校核对学校记录。

处理异常时先找原记录，保存时间、任务名和错误码。审计用于追踪关键变更，不等同于第三方消息送达证明；不能删除审计来消除重复发送或不确定状态。

## 公共资源与屏蔽词

入口：“平台管理 → 平台展示配置”。先识别这是跨学校默认配置，再编辑目标资源或规则。单校展示调整使用“展示与屏蔽词”，不要为了一个学校改变平台默认值。

保存后检查记录，并到有代表性的学校社区查看展示效果。审核标准由业务负责人确定；平台资源修改前与受影响学校确认。

## 完成与排障

完成后能找到可追溯记录与正确展示结果。权限不足时联系平台管理员；展示未变化时核对学校覆盖项、资源状态和缓存，避免反复改写无关配置。
