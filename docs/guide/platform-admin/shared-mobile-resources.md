# 共享手机资源与能力维护

入口：“业务功能 → 手机设备 → 全平台资源维护”。平台负责手机登记、学校资源池资格、通用流程和能力/业务范围办理；学校负责本校目标群、设备选择、正文与任务确认。

设备默认启用。配对成功只证明认证，不代表持续在线或允许发送。手机本人在“共享手机托管”明确同意范围后启用长期托管；无需先上报应用版本、环境或安装清单。

## 资源和范围

在“共享发送开通与调度政策”选择“批准学校使用手机”，以学校名、手机名授予资源资格。学校可自行绑定本校目标群；资格撤销或修订变化会重新核验旧依据。此资格不代替能力验收与业务范围。

在“通用能力办理”依次配置流程、上传实际 APK/证据、申请人工采样与两条桌面路径无发送验证、冻结发行、记录有限测试验收、激活发行、批准明确业务范围。界面使用下拉选择及表单，管理员不输入 JSON、UUID、摘要或 SQL。

限定测试和生产分别办理。初次限定测试可在真实无发送验证后自举，不要求先有生产发送成功；生产须另有完整用例、真实测试发送和 72 小时证据。能力验收可供多校复用，群的实际定位与绑定检查仍逐项验证。

## 政策和支持

“配置发送政策”设置禁用/仅草稿/仅预览/启用，以及独立的限定测试/生产阶段、时段、额度、间隔、确认有效期与自动检查重试。缩短配置不能覆盖冻结的人工最低间隔。

学校提交的“申请适配支持”在办理页流转，平台查看真实失败诊断并记录处理意见、关联修复发行或不受理。成功路径不收集企业微信版本清单。不要用缺少环境记录作为不允许手机入选的理由。

完整步骤、约束和升级方式见[共享发送运行手册](../../runbooks/shared-mobile-send.md)。
