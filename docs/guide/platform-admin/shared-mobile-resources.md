# 手机群消息使用管理

入口：“手机群消息使用管理”。平台管理员只处理学校、候选手机、目标群、使用期限和额度。

1. 点击“开通使用”，选择学校、手机和目标群，也可在同页填写新增群的实际搜索名；填写有限额度及有效期。离线手机可以入选。只有明确勾选“包含本校后续新增群”才自动包括新增目标。
2. 核对摘要中的学校、手机、群、额度、有效期和业务方案，点击“确认开通”。系统统一关联资源和执行依据；手机暂不可用时保留使用范围，恢复可用后系统自动继续。

学校在原已批准范围内直接使用原授权、共享原额度；其他申请由平台在同页批准或退回。摘要过期或资源范围变化时重新核对，不静默扩大权限。

列表分别展示审批、使用状态和手机现场条件。可暂停、恢复、撤销、续期或报告问题；说明和处理记录随使用对象保留。续期产生新版本并共享累计额度，不延长旧任务确认期。手机资格或群搜索名变化须重新核对。

管理员只管理业务范围、发送开关、时段和额度。手机本人一次启用托管并开启系统权限，后续检查自动完成。应用版本暂不支持时，使用管理显示具体状态并提供“报告问题”，无需管理员准备文件、证据或使用命令行工具。

未配置平台发送方案时使用系统默认设置，可直接办理使用范围并提交任务。平台方案控制实际执行的时段、间隔和额度；暂停执行不阻止任务确认排队，也不使已批准的使用范围失效。

任务预览分别显示受理检查与手机执行状态。手机状态待同步、过期、离线或忙碌不等于未授权；无需因此重复启用托管。实际执行等待手机更新状态并满足条件。

平台已建立手机与本校目标群的有效绑定（共享池手机还需具备本校使用资格）时，本校管理员可直接预览并确认发送，无需另办“测试/生产阶段放行”。已有使用管理记录的范围继续遵守审批、期限、暂停、撤销和额度限制，不因绑定仍在而绕过这些设置。

确认发送失败会弹窗说明具体原因，关闭后保留正文、手机选择与原预览；处理问题后可以重新预览并提交。平台管理员需要在学校成员管理中取得本校管理员角色才能确认发送。
