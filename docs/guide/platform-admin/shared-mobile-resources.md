# 手机群消息使用管理

入口：“手机群消息使用管理”。平台管理员只处理学校、候选手机、目标群、使用期限和额度。

1. 点击“开通使用”，选择学校、手机和目标群，也可在同页填写新增群的实际搜索名；填写有限额度及有效期。离线手机可以入选。只有明确勾选“包含本校后续新增群”才自动包括新增目标。
2. 核对摘要中的学校、手机、群、额度、有效期和业务方案，点击“确认开通”。系统统一关联资源和执行依据；产品未交付时显示等待交付，已有申请不会丢失。

学校在原已批准范围内直接使用原授权、共享原额度；其他申请由平台在同页批准或退回。摘要过期、范围或方案变化时重新核对，不静默扩大权限。

列表分别展示审批、交付和现场条件。可暂停、恢复、撤销、续期或报告问题；说明和处理记录随使用对象保留。续期产生新版本并共享累计额度，不延长旧任务确认期。手机资格或群搜索名变化须重新核对。

管理员不上传 APK、编辑流程、做人工计时或办理技术验收。产品交付由部署人员按[独立交付工具](../../runbooks/mobile-capability-delivery.md)处理。
