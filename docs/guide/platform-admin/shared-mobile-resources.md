# 手机群消息业务方案与资源约束

系统管理员在“默认手机群消息业务方案”维护默认执行规则，在业务单位的“手机接收配置”维护专属方案。业务单位用于方案适用和消息归属，不是权限分区；手机、目标和绑定仍全局管理。

## 默认与单位方案

单位专属方案存在时完整采用专属方案；未配置时使用管理员默认方案；默认方案也未保存时使用系统内置默认值。内置设置按 Asia/Shanghai 每天全天开放，各额度维度最小间隔 30 秒、3600 秒内最多 30 次、每日最多 150 次。

编辑方案需核对执行开关、时区、时段、额度和变更理由后确认。单位页显示实际来源，可显式恢复默认。恢复、修改、单位更名不会重置累计消耗。默认方案只影响继承它的单位，不叠加限制专属单位。

额度分别约束本单位总量、本单位每台手机和本单位每个目标群。多个单位使用同一默认方案时分别累计；同一单位的多条接收配置共同累计。无单位手动任务使用默认方案，采用独立计量上下文，不创建默认单位。

关闭执行仍允许创建、预览、确认和受理任务，仅等待后续签发，不消耗候选失败轮次。重新开启后，关闭期间受理且授权仍有效的任务可以继续调度。任务已确认的时段、额度和间隔保持冻结，签发前同时检查当前同单位方案；已交付手机的签名包保持原约束，手机不再联网复核或续租。

## 手机和目标选择

自动消息的手机、群及轮询／全部手机模式在单位接收配置维护，启用时授予后续新消息的链路授权。手动任务直接选择本次目标、正文和候选范围，预览后确认发送。不再单独办理手机群范围开通、申请审批或续期。

同一群可供多条配置使用，系统逐消息冻结正文、目标和候选。所选手机是首选，只能在已确认候选中自动换机；新增群或绑定不扩大已有任务授权。全部手机模式下每台手机具有独立发送责任，可能向同一实际群发送多次。

## 真实资源约束

“手机目标群”页面的“手机与目标群候选绑定”可维护绑定启用状态、可选累计调用上限及有效期限。留空的可选约束不增加限制；同一真实绑定跨单位共享其累计预算，修改额度、延长期限或重新启用不重置累计消耗。资源累计预算与单位周期额度分别检查。

设备、目标与绑定的资格、账号授权、任务确认期限和单次执行授权继续独立生效。停用某绑定只约束该真实关系，不等于暂停某业务单位全部手机。设备物理占用仍约束该设备，不能同时执行两个手机操作。

业务只填写一个群名称，所有候选使用该名称，不设置搜索词、别名或手机覆盖文本。平台不管理手机 UI flow，也不查询或操作本机托管同意、暂停、恢复、撤回。设备本地准备失败按本次尝试回报。

## 下发与核对

离线、明确失败、生成包后 60 秒无接收确认且无最终结果、接收后 5 分钟无最终结果时，按已授权候选和既有预算换机。固定周期扫描结果，每个目标最多完整遍历候选 3 轮。业务时段、额度或执行开关等待不消耗失败轮次。

unknown 保留审计但不阻止按现行规则换机，跨手机可能重复。迟到回执与结果按原尝试入账，不覆盖后继身份。任务详情区分列表同步、执行包落盘确认和最终结果；查询自动下发记录时按任务、目标、手机和尝试标识核对。

重新发送须创建新意图并确认，手机上线、刷新、服务重启和人工改派不能重置耗尽的调度预算。过程验收、发行材料和产品支持审批不参与业务受理。
