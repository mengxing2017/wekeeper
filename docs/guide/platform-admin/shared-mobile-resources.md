# 手机群消息使用管理

入口：“手机群消息使用管理”。系统管理员只处理移动分发工作空间、候选手机、目标群、使用期限和额度。

1. 点击“开通使用”，选择移动分发工作空间、手机和目标群，也可在同页填写新增群名称；填写有限额度及有效期。离线手机可以入选。只有明确勾选“包含当前工作空间后续新增群”才自动包括新增目标。
2. 核对摘要中的移动分发工作空间、手机、群、额度、有效期和业务方案，点击“确认开通”。系统统一关联资源和执行依据；某手机暂不可用时保留使用范围，任务调度器继续选择同群其他已确认授权候选。

移动分发工作空间在原已批准范围内直接使用原授权、共享原额度；其他申请由系统在同页批准或退回。摘要过期或资源范围变化时重新核对，不静默扩大权限。

列表分别展示审批、使用状态和手机现场条件。可暂停、恢复、撤销、续期或报告问题；说明和处理记录随使用对象保留。续期产生新版本并共享累计额度，不延长旧任务确认期。手机资格或群名变化须重新核对。

管理员只管理业务范围、发送开关、时段和额度。手机本人一次启用托管并开启系统权限，本地准备由手机自行完成。应用版本暂不支持时，使用管理显示具体状态并提供“报告问题”，无需管理员准备文件、证据或使用命令行工具。

未配置系统发送方案时使用系统默认设置，可直接办理使用范围并提交任务。系统方案控制实际执行的时段、间隔和额度；暂停执行不阻止任务确认排队，也不使已批准的使用范围失效。

任务预览分别显示受理检查与手机执行状态。手机状态待同步、过期、离线或忙碌不等于未授权；无需因此重复启用托管。不可用手机只影响自身尝试，系统继续选择其他合法候选；全部暂不可用时保持任务已受理，在最多三轮内重新调度。

系统已建立手机与当前工作空间目标群的有效绑定（共享池手机还需具备当前工作空间使用资格）时，当前工作空间管理员可直接预览并确认发送，无需另办“测试/生产阶段放行”。已有使用管理记录的范围继续遵守审批、期限、暂停、撤销和额度限制，不因绑定仍在而绕过这些设置。

确认发送失败会弹窗说明具体原因，关闭后保留正文、手机选择与原预览；处理问题后可以重新预览并提交。系统管理员可直接管理并确认移动分发任务；普通账号需具备当前移动分发工作空间的管理员角色才能确认发送。

开通摘要按“手机 / 目标群”展示唯一业务群名。同一目标在所有候选手机上使用相同群名，不设置手机专用搜索词或别名。群名或授权范围变化后重新预览；已交付任务仍保留原签名执行包和结果记录。

重复开通相同范围优先复用原批准记录和累计预算，系统管理员也遵守此规则。已有范围若需要更长期限或不同额度，请从原记录操作，系统不会因重复开通隐式增加一份独立额度。

“续期”保留手机、群和额度，默认期限晚于原期限；“调整范围”用于修改资源或额度；待审批、退回的记录用“修改并重新申请”，保留原申请来源。续期与重新申请保留累计消耗，不重置预算。暂停的使用范围不会因续期自动恢复，需单独点击“恢复”。

主列表按使用对象显示最新申请，内部历史版本在展开行中查看。新申请待审批时，原批准范围继续按原期限生效。暂停、恢复或撤销作用于同一使用对象的各版本，避免旧版本绕过停用。

目标资料只需填写一个群名称，管理备注可选，不再填写系统别名。系统不要求另外补充完整群名；设备自行搜索并识别群，失败按本次尝试回报，不阻止系统受理和交付任务。`exact_name` 和关联身份版本字段已删除，不保留兼容分支。

一个旧尝试或旧检查的目标依赖失效时，仅结束该尚未领取许可的请求，并继续选择其他合法任务；已发放许可保留原签名、结果补报和幂等记录。手机适配、测试、验收和发行材料不参与系统业务受理。

### 下发失败与轮次上限

每个目标最多完整遍历授权候选手机 3 轮（包含首次），每轮至少等待 5 分钟。只有一台手机且一直无反馈时，三轮约 15 分钟（另加扫描及领取延迟）；已领取任务不会因心跳暂时过期或暂停而提前结束本轮。第三轮全部候选失败或不可用后，显示“任务下发失败”，停止该目标的自动下发；其他目标继续独立调度。未领取分配超过 5 分钟或已接收后 5 分钟无最终结果会切换候选，业务间隔等待不消耗轮次。

手机上线、页面刷新、服务重启和人工改派均不能重置耗尽预算。再次发送请复制原意图为新草稿并重新确认。历史结果未知不表示确定未发送，迟到结果仍会记录，迟到成功可修正目标结果。
