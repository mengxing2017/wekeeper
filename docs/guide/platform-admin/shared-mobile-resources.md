# 共享手机与目标群

学校拥有自己的手机目标群及任务，手机属于平台共享资源池。一台手机可绑定多所学校的群，一个群也可绑定多台候选手机；一次投递仍只能由一台手机执行。

学校管理员先维护目标群，再联系平台资源维护人员。在“平台功能 → 共享手机与目标群”选择学校目标群及共享手机，核实后建立绑定。学校只能查看本校绑定，不能自行取得全局设备权限，不需要维护学校设备授权名单。

下发群名是手机搜索文字。不同手机使用不同群备注时，在对应绑定填写“该手机下发群名”；留空继承群默认名。只修改默认名不会影响使用独立覆盖名的绑定。绑定不证明实际群成员身份，现场仍须核实视觉顺序第一个群结果。

停用某一绑定只影响该手机与该群，不停用手机、不影响其他学校。迁移前的绑定默认停用，须人工核实后重新启用，不通过学校授权、责任人或同名群推断关系。

共享执行升级期间，旧学校设备执行配置和任务确认停止受理；已有任务和证据保留，只有尚未领取任务可以普通取消。共享调度与新版手机协议全部验收后再开放实际发送。

## 业务能力开通

在“共享手机与目标群 → 业务能力开通”按手机名称查看连接、实际应用环境、开通进度、负责方和下一步。无需寻找或上传文件，不填写安装包、协议或摘要。

1. 在手机“本机业务能力”点击“刷新本机环境与开通进度”，回报实际应用及桌面环境。尚未确认或分身不明确时不能猜测匹配。
2. 平台只有唯一匹配的已发行产品适配时，才提供“发送到手机确认”。申请固定适配和环境，刷新或重复点击恢复原申请，不创建重复配置。
3. 手机通过 Android 原生弹窗核对平台、设备、应用、能力、配置版本和跨学校共享含义，明确同意。待确认申请可以被手机查看，不需要先启用任务执行。
4. 环境变化、发行撤回或凭据换代时重新开通；当前申请可取消，原决定与证据保留。短暂离线不删除申请或历史同意。

当前产品尚未发行经过真机验收的生产适配。页面明确提示“当前产品版本尚未提供此业务能力，暂不能开通”；可以提交支持请求、查看负责方与处理状态。负责方可登记处理说明；结单不代表适配已发行，更不代表已具备发送资格。研发通过代码审查和产品发行交付适配，不要求普通管理员制作执行规则。

平台只展示服务端当前同意回执；手机本地阻止状态须在本机核对。迟到回执或刷新不会自动解除本机阻止。正常 token 续期不改变凭据代次。

旧文件配置接口已撤销；迁移将无发行来源的手工配置停用，保留不可变版本和同意证据，不自动转换成新申请。平台、SDK、Web 和手机须整套更新。全局现场检查、学校检查邀请、共享租约、调度与单次许可仍待交付；实际发送保持关闭，不能把开通申请成功当作业务已经可用。
