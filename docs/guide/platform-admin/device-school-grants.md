# 学校设备使用授权

学校设备授权由平台管理员明确维护，不由设备保管人的学校角色、手机真实登录账号或发送账号登记推导。原有企业微信官方客户群与群发不需要这项授权。

## 授予使用权

1. 打开“平台功能 → 学校设备授权”。
2. 选择“授予使用权”，明确选择学校、手机设备和用途。
3. 保存后由学校管理员维护手机目标与设备绑定。

设备候选支持翻页。授予使用权不代表设备已在线、手机已接受执行授权，也不代表已确认任何发送任务。手机现场接受、执行配置和任务确认仍需按新版业务流程分别完成。

重新授予或修改用途会推进授权版本，应重新核对手机接受范围，不能视为原授权自动继续生效。

## 撤销使用权

在授权列表选择“撤销”并确认影响。撤销后本校不能再使用这项授权取得新的执行许可，其他学校的独立授权不因本次撤销而改变。

已经跨过许可检查点的操作不能保证瞬时撤回，存在未决结果时必须保留证据并核对，不能通过重复新建任务解决。撤销手机使用权不会停用官方客户群或阻止原有企业微信官方群发。
