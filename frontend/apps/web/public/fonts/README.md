# AlibabaSans

Font files mirror the font-face resources used by https://preview.pro.ant.design/welcome/ and `../ant-design-pro/src/global.less` (checked 2026-10-27).

The weight mapping in `src/shared/fonts.css` matches that reference, including its 600/700 URLs. Fonts are served locally so the application does not depend on the external font CDN at runtime.

Source CDN: https://mdn.alipayobjects.com/huamei_iwk9zp/afts/file/
