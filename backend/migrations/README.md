# 数据库初始化与领域边界

项目尚未上线，没有历史业务数据。当前 18 份 SQL 是空库初始化基线，只定义当前有效结构；不运行历史表创建、数据回填、字段重命名、退场清理或旧版本升级流程。

| 版本后缀 | 文件领域 | 内容 |
| --- | --- | --- |
| 201 | identity | 账号、会话、审计、应用元数据与媒体资产 |
| 202 | wecom_resources | 企业微信通讯录、群资源、同步、发送资格及渠道健康 |
| 203 | broadcast | 群发任务、冻结快照、批次、目标与操作记录 |
| 204 | device_control | 设备注册、凭据、认证 WSS 会话、心跳与控制命令 |
| 205 | mobile_resources | 手机目标、绑定、共享委托、运行配置与资源事件 |
| 206 | mobile_adapter_records | 手机适配、支持与证据记录，不作为业务运行前置条件 |
| 207 | mobile_usage | 手机使用授权、范围、确认、额度与事件 |
| 208 | mobile_tasks | 草稿、预览、确认、任务目标、候选计划、尝试与调度状态 |
| 209 | mobile_execution | 单次执行授权、持久交付出站、交付结果及执行额度 |
| 210 | source_access | 来源调用方、凭据、nonce、查询用量与访问审计 |
| 211 | source_routing | 业务单位、来源路由、凭据关联、收件及消息交接 |
| 212 | keyword_filter | 敏感词规则头、不可变版本与默认关闭的总开关 |
| 213 | advertising | 广告素材版本、投放、单位计数与逐消息决策 |
| 214 | orchestration | 分发来源、资源策略、消息快照、编排、委托及渠道执行证据 |
| 215 | product_requests | 业务请求、预览、决策回放与事件 |
| 216 | mobile_dispatch_records | 任务受理、候选核对与调度操作记录 |
| 217 | relationships_and_projections | 前向跨领域外键、依赖后续领域函数的触发器及查询视图 |
| 218 | initial_configuration | 当前默认配置与唯一的初始全局敏感词版本 |

版本完整前缀为 `202611170`。领域文件内保留本领域函数、表、主键、索引、已满足依赖的外键和触发器；跨领域依赖闭环在 217 收尾。218 在约束及触发器建立后初始化配置，不创建旧工作空间规则、历史规则版本或升级重查任务。适配记录仅保存现有能力及证据，不向手机任务增加研发审批门禁。

SQLx 在启动时按版本递增执行并记录账本；再次启动跳过已完成迁移。后续结构变更新增递增的前向迁移。旧开发库需要完整重建 schema；只删表会遗留函数和序列，不属于本基线支持的初始化方式。启动器不会自动清库、忽略校验和或改写旧迁移账本。可丢弃的 Compose 开发数据库使用根目录 `make reset-dev-database`；嵌入式开发使用独立临时库。

数据库集成测试只使用显式的 `WEKEEPER_TEST_DATABASE_URL`。`backend/tests/database.rs` 验证空库建库、SQLx 重复启动、默认配置、退场对象缺失及 WSS 控制约束；各业务集成测试验证当前外键、不可变证据和运行行为。
