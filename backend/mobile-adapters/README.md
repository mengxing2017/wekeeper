# 产品适配发行

当前没有已验收的生产适配。测试 fixture 只用于协议、边界和失败路径测试，禁止作为生产发行数据。

管理员不上传规则；`mobile_adapter_releases` 没有业务写 API。研发通过版本库审查和新的 forward-only 数据迁移交付不可变发行。发行材料须包含：

- 精确 Android API、企业微信版本名/版本码、桌面包与版本码、执行引擎及单实例条件。
- 完整声明式流程及 Rust `FlowV2.validate_shared()` 验证结果。
- 对应真实设备检查记录、证据文件摘要、执行预算与首群失败停止验收结果。
- 源代码提交、发行负责人、发行版本、变更说明和内容摘要。

迁移须取得 `pg_advisory_xact_lock(78234610243)`，在同一事务插入发行；不覆盖旧行。`content_digest` 为完整 flow 按服务端 serde_json 排序序列化后的 SHA-256；环境 JSON 使用 `onboarding::Environment` 去掉 `instance_ref` 的精确字段，未知字段或范围不会匹配。现场实例身份由手机快照绑定。不得用“最近版本”匹配。

配置摘要进一步绑定 flow、发行 ID 和环境快照 ID。环境发生变化后即使恢复原版本，也产生新的快照身份，不复活旧申请与同意。正常续期不改变凭据代次；重新配对或换代必须重新开通。

紧急撤回插入 `mobile_adapter_withdrawals`，记录原因；数据库触发器与开通/同意事务串行化。撤回只阻断后续使用，不能清理历史固定结果或 unknown。

首个真实发行、无发送现场检查、学校检查邀请、共享设备租约和完整发送模块均须独立验收。仅插入发行不能开放发送；支持请求登记为“已解决”也不会修改适配或执行资格。
